### calc-derivative-001

**problem** 求函数 $f(x)=x^2$ 在 $x=1$ 处的切线方程。

**solution** $f'(x)=2x$，所以 $f'(1)=2$。又因为 $f(1)=1$，所以切线方程为 $y-1=2(x-1)$，化简得 $y=2x-1$。

**answer** $y=2x-1$

### calc-improper-002

**problem** 判断反常积分 $\int_0^{+\infty} \frac{1}{1+x^2} dx$ 是否收敛，若收敛，求其值。

**solution** 该积分为无穷限反常积分。根据定义，先求变上限积分：$\int_0^b \frac{1}{1+x^2} dx = [\arctan x]_0^b = \arctan b - \arctan 0 = \arctan b$。再取极限：$\lim_{b \to +\infty} \arctan b = \frac{\pi}{2}$。因为极限存在且为有限常数，故该反常积分收敛。

**answer** $\frac{\pi}{2}$

**objects[1]** 蓝色曲线 $y=\frac{1}{1+x^2}$

**objects[2]** 黄色半透明填充区域（代表积分面积）

**objects[3]** 向右移动的红色垂直虚线 $x=b$

**objects[4]** 右下角动态更新的公式文本 $\lim_{b \to +\infty} \arctan b = \frac{\pi}{2}$

**steps[0]** 第一步：绘制直角坐标系，用蓝色线条画出从 $x=0$ 开始向右无限延伸的对称单峰曲线 $y=\frac{1}{1+x^2}$。

**steps[1]** 第二步：从 $x=0$ 开始，在曲线下方动态填充黄色阴影区域，代表变上限积分 $\int_0^b \frac{1}{1+x^2} dx$ 的面积。

**steps[4]** 第五步：画面右下角依次显示文字推导过程：$\lim_{b \to +\infty} \arctan b = \frac{\pi}{2}$，高亮最终结果。


### calc-param-improper-003

**problem** 求含参反常积分$I(\alpha) = \int_{0}^{+\infty} e^{-\alpha x}dx$的值（设$\alpha>0$）。

**solution** $I(\alpha) = \lim_{b \to +\infty} \int_{0}^{b} e^{-\alpha x} dx = \lim_{b \to  +\infty} \left[  -\frac{1}{\alpha} e^{-\alpha x} \right]_{0}^{b} = \lim_{b \to +\infty}  \frac{1}{\alpha} (1 - e^{-\alpha b }) = \frac{1}{\alpha}$。

**answer** $\frac{1}{\alpha}$

### calc-double-integral-004

**problem** 利用二重积分的几何意义，说明 $\iint_D (1 - x^2 - y^2) dxdy$ 的值，其中 $D$ 是单位圆盘 $x^2 + y^2 \le 1$。

**solution** 这是一个二重积分，其几何意义是以区域 $D$ 为底，曲面 $z = 1 - x^2 - y^2$ 为顶的曲顶柱体的体积。区域 $D$ 是半径为 $1$ 的圆盘，面积为 $\pi$。在柱坐标系下，该体积可以通过极坐标计算：$\iint_D (1 - x^2 - y^2) dxdy = \int_{0}^{2\pi} d\theta \int_{0}^{1} (1 - r^2) r dr = 2\pi \left[ \frac{r^2}{2} - \frac{r^4}{4} \right]_{0}^{1} = 2\pi \times \frac{1}{4} = \frac{\pi}{2}$。

**answer** $\frac{\pi}{2}$

**objects[0]** 三维空间直角坐标系 $O-xyz$

**objects[1]** 三维曲面 $z=1-x^2-y^2$（蓝色半透明，位于 $xOy$ 平面上方）

**objects[2]** 底部的单位圆盘区域 $D$（黄色平面）

**objects[3]** 从底面圆盘向上垂直延伸的细密立柱阵列（代表微元分割 $dxdy$）

**objects[4]** 右侧三维悬浮公式 $V = \iint_D (1 - x^2 - y^2) dxdy = \frac{\pi}{2}$

**steps[0]** 第一步：初始化三维视角，缓慢旋转镜头，展示三维坐标系 $O-xyz$ 以及底部平面上的单位圆盘区域 $D$（黄色高亮）。

**steps[1]** 第二步：从底面区域 $D$ 开始，动态向上绘制蓝色的三维曲面 $z=1-x^2-y^2$。

**steps[2]** 第三步：在底面区域 $D$ 内，生成大量细密的垂直立柱，这些立柱的顶部均与蓝色曲面相交。

**steps[3]** 第四步：镜头缓慢拉近并旋转到侧上方视角，让观众清晰看到这些由底面积和曲面高度构成的曲顶柱体。

**steps[4]** 第五步：动态展示微元叠加过程，利用动画将所有立柱的体积凝聚成一个整体的体积概念。

**steps[5]** 第六步：画面右侧悬浮显示计算过程和最终结果 $V = \frac{\pi}{2}$。


### calc-green-005

**problem** 利用格林公式计算曲线积分 $\oint_L x dy - y dx$，其中 $L$ 是正向圆周 $x^2 + y^2 = a^2$。

**solution** 设 $P(x,y) = -y$，$Q(x,y) = x$。则 $\frac{\partial Q}{\partial x} = 1$，$\frac{\partial P}{\partial y} = -1$。由格林公式，原积分 $= \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dxdy = \iint_D (1 - (-1)) dxdy = 2 \iint_D dxdy$。因为 $\iint_D dxdy$ 等于圆盘的面积 $\pi a^2$，所以原积分 $= 2 \pi a^2$。

**answer** $2\pi a^2$

**objects[1]** 红色圆周曲线 $L$，带有逆时针方向箭头

**objects[2]** 内部区域 $D$ 的蓝色半透明填充

**objects[3]** 圆内区域的向量场箭头（代表 $P$ 和 $Q$ 的分量）

**objects[4]** 右侧文字公式 $\oint_L P dx + Q dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dxdy$

**steps[0]** 第一步：画出直角坐标系，用红色绘制一个以原点为圆心、半径为 $a$ 的圆形路径 $L$。

**steps[1]** 第二步：在圆的边界上添加逆时针方向的红色箭头，标出正向路径。

**steps[2]** 第三步：用蓝色半透明颜色填充圆内部的区域 $D$，代表边界 $L$ 围成的闭区域。

**steps[3]** 第四步：在圆的区域内随机绘制一些微小的向量箭头，示意在向量场中每个点的方向。

**steps[4]** 第五步：画面右侧同步展示偏导数计算推导：$\frac{\partial Q}{\partial x} = 1$，$\frac{\partial P}{\partial y} = -1$。

**steps[5]** 第六步：高亮显示格林公式等式，并强调左边的边界积分等价于右边区域的二重积分，最终展现结果 $2\pi a^2$。


### calc-limit-006

**problem** 求极限 $\lim_{x \to 0} \frac{\sin x}{x}$ 的值。

**solution** 利用夹逼定理（Squeeze Theorem）进行几何证明。在单位圆中，设圆心角为 $x$（$0 < x < \frac{\pi}{2}$），比较 $\triangle OAB$、扇形 $OAB$ 和 $\triangle OAC$ 的面积。可以推导出不等式 $\sin x < x < \tan x$。同时除以 $\sin x$ 得到 $1 < \frac{x}{\sin x} < \frac{1}{\cos x}$。取倒数得 $\cos x < \frac{\sin x}{x} < 1$。由于 $\frac{\sin x}{x}$ 为偶函数，$x \to 0^-$ 时结论同样成立。当 $x \to 0$ 时，$\cos x \to 1$，由夹逼定理可得 $\lim_{x \to 0} \frac{\sin x}{x} = 1$。

**answer** 1

**objects[3]** 从 $A$ 点 $(1,0)$ 出发的垂直切线，交射线于 $C$ 点

**objects[4]** 从 $B$ 点向 x 轴作垂线，垂足为 $D$ 点

**objects[5]** 高亮的黄色三角形 $OAB$

**objects[6]** 高亮的蓝色扇形 $OAB$

**objects[7]** 高亮的红色三角形 $OAC$

**objects[8]** 右侧悬浮公式 $\cos x < \frac{\sin x}{x} < 1$

**steps[0]** 第一步：绘制直角坐标系和单位圆。在 x 轴上标出点 $A(1,0)$，并在原点画出一条与 x 轴正方向呈约 45 度的射线。

**steps[1]** 第二步：射线与单位圆交于点 $B$，从 $B$ 点向 x 轴作垂线，垂足为 $D$。用黄色半透明填充三角形 $OAB$。

### calc-area-008

**problem** 计算由极坐标方程 $r = 2a\cos\theta$（$a>0$）所围成的图形的面积。

**solution** 该方程表示圆心在 $(a,0)$、半径为 $a$ 的圆。在极坐标中，$r = 2a\cos\theta \ge 0$，因此角度 $\theta$ 的取值范围为 $[-\frac{\pi}{2}, \frac{\pi}{2}]$。面积 $S = \frac{1}{2} \int_{-\pi/2}^{\pi/2} r^2 d\theta = \frac{1}{2} \int_{-\pi/2}^{\pi/2} (2a\cos\theta)^2 d\theta = \frac{1}{2} \int_{-\pi/2}^{\pi/2} 4a^2 \cos^2\theta d\theta = 2a^2 \int_{-\pi/2}^{\pi/2} \frac{1+\cos2\theta}{2} d\theta = a^2 [\theta + \frac{1}{2}\sin2\theta]_{-\pi/2}^{\pi/2} = a^2 [\frac{\pi}{2} - (-\frac{\pi}{2})] = \pi a^2$。

**answer** $\pi a^2$

**objects[1]** 极坐标曲线 $r = 2a\cos\theta$ 所围成的圆形

**objects[2]** 从原点出发扫过的射线

**objects[3]** 由两条射线和一个圆弧围成的扇形微元

**steps[3]** 第四步：在扫过时，标出由夹角 $d\theta$ 构成的微小扇形，展示面积微元 $\frac{1}{2} r^2 d\theta$。

### calc-area-009

**problem** 求摆线 $x = a(t - \sin t), y = a(1 - \cos t)$ 的一拱（$0 \le t \le 2\pi$）与 $x$ 轴所围成的面积。

**solution** 摆线的一拱与 $x$ 轴围成封闭图形。面积 $S = \int_{0}^{2\pi a} y dx$。将参数方程代入，得 $S = \int_{0}^{2\pi} a(1 - \cos t) \cdot d[a(t - \sin t)] = \int_{0}^{2\pi} a(1 - \cos t) \cdot a(1 - \cos t) dt = a^2 \int_{0}^{2\pi} (1 - 2\cos t + \cos^2 t) dt$。利用三角函数积分性质，其中 $\cos t$ 在周期内积分为0，故 $S = a^2 \int_{0}^{2\pi} (1 + \frac{1+\cos 2t}{2}) dt = a^2 \cdot 3\pi = 3\pi a^2$。

**answer** $3\pi a^2$

**objects[2]** 摆线与x轴围成的黄色半透明区域

**objects[3]** 参数t动态变化指示点

**objects[4]** 沿x轴滚动的圆

**steps[2]** 第三步：当圆滚过一个完整周期（$0 \le t \le 2\pi$）后，摆线与x轴围成了一个封闭的拱形区域，用黄色半透明填充。

### calc-area-010

**problem** 计算由曲线 $y=\ln x$、直线 $y=-x+e+1$ 以及 $x$ 轴围成的封闭图形的面积。

**solution** 联立 $y=\ln x$ 与 $y=-x+e+1$ 得交点为 $(e, 1)$。该封闭图形以 $x$ 轴为下边界，由两部分组成：在 $[1, e]$ 上，上边界为曲线 $y=\ln x$；在 $[e, e+1]$ 上，上边界为直线 $y=-x+e+1$。面积 $S = \int_1^e \ln x dx + \int_e^{e+1} (-x+e+1) dx$。第一项：$\int_1^e \ln x dx = [x\ln x - x]_1^e = (e - e) - (0 - 1) = 1$。第二项：$\int_e^{e+1} (-x+e+1) dx = [-\frac{1}{2}x^2 + (e+1)x]_e^{e+1} = \frac{1}{2}$。总面积 $S = 1 + \frac{1}{2} = \frac{3}{2}$。

**answer** $\frac{3}{2}$

**objects[2]** 红色直线 $y=-x+e+1$

**objects[3]** 由两条曲线和 x 轴围成的封闭区域（黄色填充）

**objects[4]** 区分 $[1,e]$ 与 $[e,e+1]$ 的分段垂直虚线

**objects[5]** 垂直微元矩形

### calc-area-011

**problem** 计算由曲线 $y = |x^2 - 1|$ 与直线 $y = 1$ 所围成的封闭图形的面积。

**solution** 曲线 $y = |x^2 - 1|$ 与直线 $y = 1$ 的交点为 $x = 0$ 和 $x = \pm\sqrt{2}$。因为图形关于y轴对称，可以计算右半部分 $[0, \sqrt{2}]$ 的面积再乘以2。当 $0 \le x \le 1$ 时，$y = 1 - x^2$，当 $1 \le x \le \sqrt{2}$ 时，$y = x^2 - 1$。面积 $S = 2 \left( \int_0^1 (1 - (1-x^2)) dx + \int_1^{\sqrt{2}} (1 - (x^2-1)) dx \right) = 2 \left( \int_0^1 x^2 dx + \int_1^{\sqrt{2}} (2 - x^2) dx \right) = 2 \left( \frac{1}{3} + (2x - \frac{x^3}{3})|_1^{\sqrt{2}} \right) = 2 \left( \frac{1}{3} + (2\sqrt{2} - \frac{2\sqrt{2}}{3}) - (2 - \frac{1}{3}) \right) = 2 \left( \frac{1}{3} + \frac{4\sqrt{2}}{3} - \frac{5}{3} \right) = \frac{8(\sqrt{2}-1)}{3}$。

**steps[1]** 第二步：先分割出一半面积（1/2）的矩形，用蓝色填充，显示部分和 $S_1 = \frac{1}{2}$。

**steps[2]** 第三步：在剩余的空间中再分割出 1/4 面积的矩形，用绿色填充，显示部分和 $S_2 = \frac{1}{2} + \frac{1}{4}$。

**steps[3]** 第四步：接着不断分割出 $\frac{1}{8}, \frac{1}{16}, \frac{1}{32}$ 等更小的矩形，用不同颜色区分。

**steps[4]** 第五步：随着分割次数趋向无穷，剩余未分配的面积越来越小，最终无限趋近于 $0$。

**steps[5]** 第六步：展示求和公式 $\sum_{k=1}^{\infty} \frac{1}{2^k} = 1$，所有矩形面积之和等于 1，直观展示可列可加性。

answer $y=2x-1$

calc-improper-002

problem 判断反常积分 $\int_0^{+\infty} \frac{1}{1+x^2} dx$ 是否收敛，若收敛，求其值。

solution 该积分为无穷限反常积分。根据定义，先求变上限积分：$\int_0^b \frac{1}{1+x^2} dx = [\arctan x]_0^b = \arctan b - \arctan 0 = \arctan b$。再取极限：$\lim_{b \to +\infty} \arctan b = \frac{\pi}{2}$。因为极限存在且为有限常数，故该反常积分收敛。

answer $\frac{\pi}{2}$

problem 求含参反常积分$I(\alpha) = \int_{0}^{+\infty} e^{-\alpha x}dx$的值（设$\alpha\gt 0$）。

solution $I(\alpha) = \lim_{b \to +\infty} \int_{0}^{b} e^{-\alpha x} dx = \lim_{b \to +\infty} \left[ -\frac{1}{\alpha} e^{-\alpha x} \right]_{0}^{b} = \lim_{b \to +\infty} \frac{1}{\alpha} (1 - e^{-\alpha b }) = \frac{1}{\alpha}$。

answer $\frac{1}{\alpha}$

solution 这是一个二重积分，其几何意义是以区域 $D$ 为底，曲面 $z = 1 - x^2 - y^2$ 为顶的曲顶柱体的体积。区域 $D$ 是半径为 $1$ 的圆盘，面积为 $\pi$。在柱坐标系下，该体积可以通过极坐标计算：$\iint_D (1 - x^2 - y^2) dxdy = \int_{0}^{2\pi} d\theta \int_{0}^{1} (1 - r^2) r dr = 2\pi \left[ \frac{r^2}{2} - \frac{r^4}{4} \right]_{0}^{1} = 2\pi \times \frac{1}{4} = \frac{\pi}{2}$。

answer $\frac{\pi}{2}$

problem 利用格林公式计算曲线积分 $\oint_L x dy - y dx$，其中 $L$ 是正向圆周 $x^2 + y^2 = a^2$。

solution 设 $P(x,y) = -y$，$Q(x,y) = x$。则 $\frac{\partial Q}{\partial x} = 1$，$\frac{\partial P}{\partial y} = -1$。由格林公式，原积分 $= \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dxdy = \iint_D (1 - (-1)) dxdy = 2 \iint_D dxdy$。因为 $\iint_D dxdy$ 等于圆盘的面积 $\pi a^2$，所以原积分 $= 2 \pi a^2$。

answer $2\pi a^2$

problem 求极限 $\lim_{x \to 0} \frac{\sin x}{x}$ 的值。

solution 利用夹逼定理（Squeeze Theorem）进行几何证明。在单位圆中，设圆心角为 $x$（$0 \lt x \lt \frac{\pi}{2}$），比较 $\triangle OAB$、扇形 $OAB$ 和 $\triangle OAC$ 的面积。可以推导出不等式 $\sin x \lt x \lt \tan x$。同时除以 $\sin x$ 得到 $1 \lt \frac{x}{\sin x} \lt \frac{1}{\cos x}$。取倒数得 $\cos x \lt \frac{\sin x}{x} \lt 1$。由于 $\frac{\sin x}{x}$ 为偶函数，$x \to 0^-$ 时结论同样成立。当 $x \to 0$ 时，$\cos x \to 1$，由夹逼定理可得 $\lim_{x \to 0} \frac{\sin x}{x} = 1$。

answer 1

problem 计算由曲线 $y=\ln x$、直线 $y=-x+e+1$ 以及 $x$ 轴围成的封闭图形的面积。

solution 联立 $y=\ln x$ 与 $y=-x+e+1$ 得交点为 $(e, 1)$。该封闭图形以 $x$ 轴为下边界，由两部分组成：在 $[1, e]$ 上，上边界为曲线 $y=\ln x$；在 $[e, e+1]$ 上，上边界为直线 $y=-x+e+1$。面积 $S = \int_1^e \ln x dx + \int_e^{e+1} (-x+e+1) dx$。第一项：$\int_1^e \ln x dx = [x\ln x - x]_1^e = (e - e) - (0 - 1) = 1$。第二项：$\int_e^{e+1} (-x+e+1) dx = [-\frac{1}{2}x^2 + (e+1)x]_e^{e+1} = \frac{1}{2}$。总面积 $S = 1 + \frac{1}{2} = \frac{3}{2}$。

answer $\frac{3}{2}$

problem 计算由曲线 $y = |x^2 - 1|$ 与直线 $y = 1$ 所围成的封闭图形的面积。

solution 曲线 $y = |x^2 - 1|$ 与直线 $y = 1$ 的交点为 $x = 0$ 和 $x = \pm\sqrt{2}$。因为图形关于y轴对称，可以计算右半部分 $[0, \sqrt{2}]$ 的面积再乘以2。当 $0 \le x \le 1$ 时，$y = 1 - x^2$，当 $1 \le x \le \sqrt{2}$ 时，$y = x^2 - 1$。面积 $S = 2 \left( \int_0^1 (1 - (1-x^2)) dx + \int_1^{\sqrt{2}} (1 - (x^2-1)) dx \right) = 2 \left( \int_0^1 x^2 dx + \int_1^{\sqrt{2}} (2 - x^2) dx \right) = 2 \left( \frac{1}{3} + (2x - \frac{x^3}{3})|_1^{\sqrt{2}} \right) = 2 \left( \frac{1}{3} + (2\sqrt{2} - \frac{2\sqrt{2}}{3}) - (2 - \frac{1}{3}) \right) = 2 \left( \frac{1}{3} + \frac{4\sqrt{2}}{3} - \frac{5}{3} \right) = \frac{8(\sqrt{2}-1)}{3}$。

answer $\frac{8(\sqrt{2}-1)}{3}$

problem 说明当 $n$ 很大，$p$ 很小时，二项分布 $B(n, p)$ 可以近似为泊松分布 $P(\lambda)$，其中 $\lambda = np$。

solution 二项分布的概率质量函数为 $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$。当 $n \to \infty$，$p \to 0$ 且 $np \to \lambda$ 时，利用极限 $\lim_{n \to \infty} (1 - \frac{\lambda}{n})^n = e^{-\lambda}$，可以推导出 $P(X=k) \to \frac{\lambda^k e^{-\lambda}}{k!}$，这正是泊松分布的概率质量函数。

answer 当 $n \to \infty$、$p \to 0$ 且 $np \to \lambda$ 时，$B(n,p)$ 的概率质量函数趋近于泊松分布 $P(\lambda)$ 的概率质量函数 $\frac{\lambda^k e^{-\lambda}}{k!}$

answer 约 9.02%

solution 已知 $X \sim U(0,1)$，其概率密度函数为 $f_X(x) = 1$（当 $0 \lt x \lt 1$）。采用分布函数法：先求 $Y$ 的分布函数 $F_Y(y) = P(Y \le y) = P(X^2 \le y) = P(-\sqrt{y} \le X \le \sqrt{y})$。因为 $X \in (0,1)$，所以 $F_Y(y) = P(0 \lt X \le \sqrt{y}) = \sqrt{y}$（当 $0 \lt y \lt 1$）。对 $y$ 求导得 $f_Y(y) = F_Y'(y) = \frac{1}{2\sqrt{y}}$。

answer $f_Y(y) = \frac{1}{2\sqrt{y}}$，其中 $0 \lt y \lt 1$

geom-020

problem 求直线 $l: \frac{x-1}{2} = \frac{y+1}{-1} = \frac{z}{3}$ 与平面 $\pi: 2x - y + 3z = 5$ 的夹角。

solution 直线的方向向量为 $\vec{s} = (2, -1, 3)$，平面的法向量为 $\vec{n} = (2, -1, 3)$。计算两向量的点积 $\vec{s} \cdot \vec{n} = 2\times2 + (-1)\times(-1) + 3\times3 = 4 + 1 + 9 = 14$。两者的模长为 $|\vec{s}| = \sqrt{4+1+9} = \sqrt{14}$，$|\vec{n}| = \sqrt{14}$。设直线与平面的夹角为 $\theta$，则 $\sin\theta = \frac{|\vec{s} \cdot \vec{n}|}{|\vec{s}||\vec{n}|} = \frac{14}{\sqrt{14}\sqrt{14}} = \frac{14}{14} = 1$，故 $\theta = \frac{\pi}{2}$，即直线与平面垂直。

answer $\frac{\pi}{2}$

geom-024

problem 说明方程 $x^2 + y^2 = 4$ 在空间直角坐标系中表示什么曲面，并画出其图形。

solution 在平面直角坐标系中，方程 $x^2 + y^2 = 4$ 表示半径为 2 的圆。在空间直角坐标系中，由于方程缺少变量 $z$，说明对于任意 $z$ 值，$xOy$ 平面上的截面都是同样的圆。因此，该方程表示一个圆柱面，其母线平行于 $z$ 轴，准线为 $xOy$ 平面上的圆 $x^2 + y^2 = 4$。

answer 圆柱面，母线平行于 z 轴，准线为 xOy 平面上的圆

geom-026

problem 指出方程 $z = x^2 + 2y^2$ 表示的二次曲面类型，并分析其与平面 $y = 0$ 和 $y = 1$ 的交线。

solution 该方程为椭圆抛物面。当 $y = 0$ 时，交线为 $z = x^2$，是 $xOz$ 平面上的抛物线。当 $y = 1$ 时，交线为 $z = x^2 + 2$，依然是一条抛物线，只是顶点向上平移了 2 个单位。一般地，截面 $y=c$ 给出交线 $z=x^2+2c^2$：顶点在 $z$ 方向抬高 $2c^2$。因此，曲面可以看作截面抛物线随 $c$ 变化（顶点沿 $z$ 方向抬高 $2c^2$）叠加而成。

answer 椭圆抛物面；与平面 $y=0$ 的交线为 $z=x^2$，与平面 $y=1$ 的交线为 $z=x^2+2$

geom-028

problem 判断椭圆抛物面 $z = x^2 + y^2$ 是否为直纹面，并说明理由。

solution 不是直纹面。假设它是直纹面，则曲面上存在直线。设直线过点 $(x_0, y_0, z_0)$，方向向量为 $(l, m, n)$，参数方程为 $(x_0+lt, y_0+mt, z_0+nt)$。代入曲面方程 $z=x^2+y^2$ 并整理得 $t^2(l^2+m^2)+t(2x_0l+2y_0m-n)+(x_0^2+y_0^2-z_0)=0$。若该方程对任意 $t$ 成立，则各次项系数全为零：由 $l^2+m^2=0$ 得 $l=m=0$；再由一次项系数 $2x_0l+2y_0m-n=0$ 得 $n=0$。于是方向向量为零向量，直线退化为一个点，矛盾。因此，椭圆抛物面上不存在直线，它不是直纹面。

answer 不是直纹面

objects[1] 候选直线 $(x,y,z)=(x_0+lt,y_0+mt,z_0+nt)$

objects[2] 方向条件 $(l,m,n)\ne(0,0,0)$

steps[0] 图示候选直线只作示意；显示代入恒等式 $t^2(l^2+m^2)+t(2x_0l+2y_0m-n)+(x_0^2+y_0^2-z_0)=0$。

steps[1] 若整条直线在曲面上，该多项式对所有 $t\in\mathbb R$ 为零，故每个系数为零。

steps[2] 二次项给出 $l^2+m^2=0$，在实数域上得 $l=m=0$；一次项再给出 $-n=0$。

steps[3] 于是 $(l,m,n)=(0,0,0)$，与直线方向非零矛盾；因此曲面不含直线，也不是直纹面。

solution 根据等距变换公式 $P' = AP + \vec{b}$。先计算矩阵乘法：$AP = \begin{pmatrix} 0 & -1 & 0 \ 1 & 0 & 0 \ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} 1 \ 0 \ 0 \end{pmatrix} = \begin{pmatrix} 0 \ 1 \ 0 \end{pmatrix}$。然后加上平移向量：$P' = (0, 1, 0) + (1, 2, 3) = (1, 3, 3)$。该变换实际上是将点绕 $z$ 轴旋转 $90^\circ$，再平移。

answer $(1, 3, 3)$

problem 说明仿射变换 $x' = 2x, y' = y, z' = z$ 将球面 $x^2 + y^2 + z^2 = 1$ 变成了什么图形。

solution 将 $x = x'/2, y = y', z = z'$ 代入球面方程，得 $(x'/2)^2 + y'^2 + z'^2 = 1$，即 $\frac{x'^2}{4} + y'^2 + z'^2 = 1$。这是一个椭球面，它在 $x$ 轴方向被拉伸了 2 倍，而在 $y$ 和 $z$ 轴方向保持不变。

answer 椭球面 $\frac{x'^2}{4} + y'^2 + z'^2 = 1$

geom-031

problem 求球面 $x^2+y^2+z^2=4a^2$ 与圆柱面 $x^2+y^2=2ax$ 的交线（维维安尼曲线）的参数方程（$a>0$）。

solution 令 $x=a(1+\cos t)$，$y=a\sin t$，则 $x^2+y^2 = a^2(1+\cos t)^2 + a^2\sin^2 t = 2a^2(1+\cos t) = 2a\cdot a(1+\cos t) = 2ax$，圆柱面方程自动满足。代入球面方程 $x^2+y^2+z^2=4a^2$ 得 $z^2 = 4a^2 - 2a^2(1+\cos t) = 2a^2(1-\cos t) = 4a^2\sin^2\frac{t}{2}$。取连续参数分支 $z = 2a\sin\frac{t}{2}$（另一分支 $z = -2a\sin\frac{t}{2}$ 由参数平移 $2\pi$ 覆盖，不另取）。于是交线的参数方程为 $x=a(1+\cos t)$，$y=a\sin t$，$z=2a\sin\frac{t}{2}$，其中 $0 \le t \le 4\pi$ 覆盖整条曲线（$0 \le t \le 2\pi$ 仅覆盖上半部分）。

answer 维维安尼曲线，参数方程为 $x=a(1+\cos t)$，$y=a\sin t$，$z=2a\sin\frac{t}{2}$，其中 $0 \le t \le 4\pi$

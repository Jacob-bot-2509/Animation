## 逐题核算说明(数学验算)

### C01 导数与切线

1. **draft-c01-01**(基础,水平切线分支):$f'(x)=3x^2-6x=3x(x-2)$,零点 $x=0,2$;$f(0)=2$,$f(2)=8-12+2=-2$。两切线 $y=2$、$y=-2$。斜率零条件与函数值代入均手工复核 ✓
2. **draft-c01-02**(基础,隐函数):$(2,1)$ 在椭圆上($4+4=8$)。$2x+8yy'=0\to y'=-x/(4y)$;$(2,1)$ 处 $-2/4=-1/2$;点斜式 $y-1=-\tfrac12(x-2)\Rightarrow x+2y=4$。反代 $(2,1)$: $2+2=4$ ✓
3. **draft-c01-03**(中等,参数曲线):$dx/dt=2t$,$dy/dt=3t^2-3$。$t=2$:点 $(4,2)$,斜率 $(12-3)/4=9/4$;切线 $y-2=\tfrac94(x-4)$ 即 $y=\tfrac94x-7$,代入 $x=4$ 得 $9-7=2$ ✓。水平:$3t^2-3=0\to t=\pm1$,且 $2t\neq0$;点 $(1,\mp2)$ 由 $y=t^3-3t$ 代入 $t=\pm1$ 得 $\mp2$ ✓。竖直:$2t=0\to t=0$,$dy/dt=-3\neq0$,点 $(0,0)$,切线 $x=0$ ✓
4. **draft-c01-04**(中等,过外点):$P(1,-2)$ 不在曲线上($y(1)=-1$)。切点 $(a,a^2-2a)$,斜率 $2a-2$;代入 $P$:$-2-(a^2-2a)=(2a-2)(1-a)$;左 $-a^2+2a-2$,右 $2a-2-2a^2+2a=-2a^2+4a-2$;相减 $a^2-2a=0\to a=0,2$。$a=0$:点 $(0,0)$,线 $y=-2x$,过 $P$:$-2=-2\cdot1$ ✓;$a=2$:点 $(2,0)$,线 $y=2x-4$,过 $P$:$-2=2-4$ ✓
5. **draft-c01-05**(进阶,公切线不存在):两条切线方程 $y=2ax-a^2$ 与 $y=(-2c+2)x+c^2+1$(第二式由 $y-g(c)=g'(c)(x-c)$ 展开,$g(c)=-c^2+2c+1$:截距 $-(-2c+2)c+g(c)=2c^2-2c-c^2+2c+1=c^2+1$ ✓)。比较系数:$2a=-2c+2\to a=1-c$;$-a^2=c^2+1\to-(1-c)^2=c^2+1\to c^2-c+1=0$,$\Delta=1-4=-3<0$ 无实根,故公切线不存在 ✓

### C36 二次型正定性

1. **draft-c36-01**(基础,二元正定):$A=[[3,-1],[-1,3]]$,$\Delta_1=3$,$\Delta_2=9-1=8>0$ → 正定。配方:$3(x-y/3)^2+8y^2/3$ 展开 $=3x^2-2xy+y^2/3+8y^2/3=3x^2-2xy+3y^2$ ✓;非零点正性讨论 ✓
2. **draft-c36-02**(基础,特征值法):三对角 $A$($b=2,c=-1$)特征值 $\lambda_k=2+2(-1)\cos(k\pi/4)$,$k=1,2,3$:$2-\sqrt2,2,2+\sqrt2$,全正 → 正定 ✓(亦可由特征多项式 $\lambda^3-6\lambda^2+10\lambda-4$ 根核验)
3. **draft-c36-03**(中等,含参):$A=[[1,1,0],[1,2,0],[0,0,a]]$;$\Delta_1=1,\Delta_2=1,\Delta_3=\det A=1(2a)-1(a)=a$。正定 ⟺ $a>0$ ✓。$a=0$:$f=x^2+2xy+2y^2=(x+y)^2+y^2\ge0$,$f(0,0,1)=0$ 非零解 → 半正定非正定 ✓。$a<0$:$f(0,0,1)=a<0$ → 不定 ✓
4. **draft-c36-04**(中等,半正定+秩):$f=(x-y)^2+2(y-z)^2\ge0$;零解 $x=y=z$ 非平凡 → 半正定非正定 ✓。矩阵 $A=[[1,-1,0],[-1,3,-2],[0,-2,2]]$;$\det A=1(6-4)-(-1)(-2)=2-2=0$;二阶主子式 $3-1=2\neq0$ → 秩 2,零度 1=$\dim\{(t,t,t)\}$ ✓
5. **draft-c36-05**(进阶,反例):$A=[[0,0,1],[0,0,1],[1,1,0]]$;顺序主子式 $0,0,0$(全非负);$x^\mathsf{T}Ax=2x_1x_3+2x_2x_3$,取 $x=(1,0,-1)^\mathsf{T}$ 得 $-2<0$ → 非半正定 ✓;特征多项式 $-\lambda^3+2\lambda=-\lambda(\lambda^2-2)$,特征值 $0,\pm\sqrt2$ 含负值 ✓;非负顺序主子式但非半正定的反例成立(其 $2\times2$ 主子式 [[0,1],[1,0]] 行列式 $-1<0$,说明半正定需**全部**主子式非负)

### C52 随机变量函数的分布

1. **draft-c52-01**(基础,线性变换):$y=3x+1$ 单调,值域 $(1,4)$;$f_Y=2\cdot(y-1)/3\cdot1/3=2(y-1)/9$;$\int_1^4 2(y-1)/9\,dy=[(y-1)^2/9]_1^4=1$ ✓
2. **draft-c52-02**(基础,$\chi^2(1)$):$F_Y(y)=2\Phi(\sqrt y)-1$;$f_Y=2\varphi(\sqrt y)\cdot1/(2\sqrt y)=\varphi(\sqrt y)/\sqrt y=y^{-1/2}e^{-y/2}/\sqrt{2\pi}$,与 $\chi^2(1)$ 密度一致 ✓
3. **draft-c52-03**(中等,分段):$X\sim U(-1,2)$ 密度 $1/3$。$0<y<1$:$[-\sqrt y,\sqrt y]\subset(-1,2)$,$F=2\sqrt y/3\to f=1/(3\sqrt y)$;$1\le y<4$:交 $[-1,\sqrt y]$,$F=(\sqrt y+1)/3\to f=1/(6\sqrt y)$。总质量 $[2\sqrt y/3]_0^1+[\sqrt y/3]_1^4=2/3+1/3=1$ ✓;分界 $y=1$ 处 $1/3\to1/6$ 跳跃 ✓
4. **draft-c52-04**(中等,混合):$F_Y(y)=y/2(0<y<1)$,连续密度 $1/2$,原子 $P(Y=1)=P(X\ge1)=1/2$;期望 $1/4+1/2=3/4$;经 $X$ 直接积分 $\tfrac12(\tfrac12+1)=3/4$,两法一致 ✓
5. **draft-c52-05**(进阶,卷积):$f_Z(z)=z(0<z<1)$,$2-z(1\le z<2)$(三角密度);$P(1/2<Z<3/2)=[z^2/2]_{1/2}^1+[2z-z^2/2]_1^{3/2}=(1/2-1/8)+(15/8-3/2)=3/8+3/8=3/4$;几何验证:两端三角形各 $1/8$ ✓

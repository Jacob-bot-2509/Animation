# Animation Model Training v0.2.0

发布日期：2026-10-01
发布类型：基础设施预发布（Pre-release）

本版本同步数学动画生成项目的基础设施、修复进度和审查证据，准备进入真实数据验收阶段。不是训练完成或生产就绪版本。

## 本次交付

- JSONL 数据校验、非法样本拒绝与来源/许可证检查；train/eval/test 明确拒绝未支持的整文件 JSON 样本入口。
- 修复近重复候选截断漏检；提供阈值校准框架，未校准状态传递到 READY。
- 运行记录包含 seed、环境、git 状态和 manifest 哈希；preflight 校验绑定当前 manifest。
- READY 聚合拒绝额外失败和被同名检查遮盖的失败/UNVERIFIED。
- eval/test 冻结锁统一为 *.lock.json；自动发现范围内的坏锁拒绝写入，--force 不能绕过已发现的冻结保护。
- 冻结证据要求覆盖当前 manifest 的 eval/test 文件，并校验 manifest 绑定；本次补上缺少绑定哈希时错误放行的问题。
- split、冻结锁、运行记录接入单文件原子写入。
- 数学检查区分真、假、未证明与非断言；普通表达式不再被误判为数学证明。
- 渲染入口默认拒绝不可信代码；显式可信固定样例支持真实 MathTex 渲染，子进程使用临时工作目录，修复当前环境的 dvisvgm 路径回归。
- 同步历次审查材料、渲染验证报告、最新进度与下一周期计划。

## 验证

- **144 tests passed，29 subtests passed**。
- 包含固定可信样例的真实 MathTex 渲染、非法 API/语法失败检查。
- 新增七种 CLI 冻结证据场景：正确绑定、缺绑定、错误绑定、无关锁、部分覆盖、坏锁、无锁。
- 独立验证有效锁/坏锁漏传参数及非规范锁名路径，拒绝前原输出保持不变。
- 测试使用本地已有 Python 3.13 环境；合成样例与 mock 检查不代表真实数据已验收。
- 详细证据：[第四轮复验](reviews/2026-10-01-br-recheck-round4/REVIEW.md)。

## 已知限制

- **正式 READY 尚缺“当前资产验收证据缺失”的显式阻断**。固定 MathTex/数学样例只证明环境能运行，不能替代当前资产验收；不能仅凭当前 CLI 的 READY 宣称训练就绪。
- 真实数据来源/许可证证据、真实数据验收及分语言/长度的近重复阈值校准尚未完成。
- 文件系统、网络和内存隔离尚未实施；trusted=True 仅用于已审查的固定可信样例，不适用于不可信生成代码。
- 单文件原子写入不等于多文件发布事务；恢复机制、正式实验重放及固定指标/逐样本评测契约仍待阶段验收。
- 冻结锁自动发现有目录范围约定，跨目录使用显式锁参数；不是操作系统级不可变保护。
- 没有真实模型训练、baseline/消融结果或生产部署；代码许可证尚待确定。

## 逐题核算说明(数学验算)

### C11 幂级数收敛域与和函数

1. **draft-c11-01**(基础):根值法 $\lim\sqrt[n]{a_n}=(1-\frac{1}{n+1})^n\to e^{-1}$,R=e。端点通项 $\exp(n^2\ln(1-\frac1{n+1})+n)$:$n^2/(n+1)=n-1+1/(n+1)$,指数 $\to 1-\frac12=\frac12$,通项 $\to e^{1/2}\neq0$ → 两端点发散,域 $(-e,e)$ ✓
2. **draft-c11-02**(基础):$|x|<1$ 收敛;x=1 为 p=1/2 级数发散;x=−1 莱布尼茨收敛。域 $[-1,1)$ ✓
3. **draft-c11-03**(中等):拆项 $\frac1{n(n+1)}=\frac1n-\frac1{n+1}$;$S=A-(A-x)/x=1+\frac{(1-x)\ln(1-x)}x$。数值核验:S(0)=0;S(1)=∑1/(n(n+1))=1(裂项),公式极限 $1+\lim(1-x)\ln(1-x)/x=1$ ✓;S(−1)=1+2ln2/(−1)=1−2ln2,直接求和 $\sum(-1)^n/(n(n+1))=-ln2-(ln2-1)=1-2ln2$ ✓。域 $[-1,1]$(端点绝对收敛,$1/(n(n+1))$ 可和)✓
4. **draft-c11-04**(中等):比值极限 $\frac{n+1}{n}\cdot\frac{|x|}{n+1}\to0$ → 域 ℝ;$\sum\frac{nx^n}{n!}=x\sum_{m\ge0}\frac{x^m}{m!}=xe^x$ ✓
5. **draft-c11-05**(进阶):域 $(-1,1]$(x=1 莱布尼茨收敛,x=−1 调和发散);$S=-\ln(1+x)$;x=1 由阿贝尔定理 $S(1)=-\ln2$ ✓

### C33 矩阵求逆与可逆性

1. **draft-c33-01**(基础):增广消元得 $A^{-1}=[[1,-2,1],[0,1,-2],[0,0,1]]$;$AA^{-1}$:行 1 $[1,2,3]\cdot$三列 $=(1,0,0)$ 等,全部核对 ✓
2. **draft-c33-02**(基础):按第一行展开 $\det A=(a-1)-(1-a)+a(1-a^2)=3a-2-a^3=-(a-1)^2(a+2)$;可逆 ⟺ $a\neq1,-2$ ✓。a=0:$A^{-1}=\frac12[[1,1,-1],[1,-1,1],[-1,1,1]]$,逐行相乘核对 $AA^{-1}=I$ ✓
3. **draft-c33-03**(中等):分块 $A=[[2,1],[1,1]],b=(1,0)^\mathsf T,d=2$;$A^{-1}=[[1,-1],[-1,2]]$,$A^{-1}b=(1,-1)^\mathsf T$;块公式得 $M^{-1}=[[1,-1,-1/2],[-1,2,1/2],[0,0,1/2]]$,$MM^{-1}=I$ 逐行核对 ✓(含第三列 $[2,1,1]\cdot(-1/2,1/2,1/2)=0$)
4. **draft-c33-04**(中等):$L=[[1,0,0],[0,1,0]]$:$LA=I_2$ ✓;$R=[[1,0],[0,1],[0,0]]$:$BR=I_2$ ✓。左逆一般形式:行向量 $(\ell_1,\ell_2)$ 满足 $\ell_1(1,0,1)^\mathsf T=1,\ell_1(0,1,1)^\mathsf T=0,\ell_2(1,0,1)^\mathsf T=0,\ell_2(0,1,1)^\mathsf T=1$,解为 $\ell_1=(1-t,-t,t),\ell_2=(-s,1-s,s)$;第二例 $t=1,s=-1$:$L'=[[0,-1,1],[1,2,-1]]$,$L'A=I_2$ 已逐项核对 ✓
5. **draft-c33-05**(进阶):$N=[[0,1,0],[0,0,1],[0,0,0]],N^2=[[0,0,1],[0,0,0],[0,0,0]],N^3=0$;$A=I+aN+a^2N^2$。$M=aN+a^2N^2,M^2=a^2N^2,M^3=0$;$A^{-1}=I-M+M^2=I-aN=[[1,-a,0],[0,1,-a],[0,0,1]]$;$AA^{-1}=I$ 核对(含 (1,3) 项 $a^2-a^2=0$)✓;det=1 与 a 无关 ✓

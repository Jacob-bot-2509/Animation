## 逐题核算说明(数学验算)

### C07 极坐标面积

1. **draft-c07-01**(基础):一叶角域 $[0,\pi/3]$;$\frac12\cdot4\cdot\frac13\cdot\frac\pi2=\frac\pi3$ ✓
2. **draft-c07-02**(基础):$\frac12(2\pi+0+\pi)=\frac{3\pi}2$ ✓
3. **draft-c07-03**(中等):一叶 $[-\pi/4,\pi/4]$;$\frac12\cdot\frac12\cdot\frac\pi2=\frac\pi8$,乘 4 得 $\frac\pi2$ ✓
4. **draft-c07-04**(中等):$[2\theta+2\sin2\theta]_{-\pi/3}^{\pi/3}=\frac{4\pi}3+2\sqrt3$;与两圆面积差验算($4\pi-(8\pi/3-2\sqrt3)$)一致 ✓
5. **draft-c07-05**(进阶):角域 $[-\pi/4,\pi/4]$;每叶 $\frac12$,总面积 1 ✓

### C08 参数曲线面积

1. **draft-c08-01**(基础):$-ab\int\sin^2=-ab\pi$,绝对值 $\pi ab$ ✓
2. **draft-c08-02**(基础):$3a^2\cdot\frac{3!!\cdot1!!}{6!!}\cdot\frac\pi2=3a^2\cdot\frac{3}{48}\cdot\frac\pi2$... 精确:$\int_0^{\pi/2}\sin^4t\cos^2t\,dt=\frac{(3!!)(1!!)}{6!!}\cdot\frac\pi2=\frac{3}{48}\cdot\frac\pi2=\frac{\pi}{32}$;$3a^2\cdot\frac{\pi}{32}=\frac{3\pi a^2}{32}$,乘 4 得 $\frac{3\pi a^2}8$ ✓
3. **draft-c08-03**(中等):$xy'-yx'=\frac{9t^2}{(1+t^3)^2}$ 推导逐项核对;$A=\frac12\cdot3=\frac32$ ✓(广义积分 $[-\frac{3}{1+t^3}]_0^{+\infty}=3$)
4. **draft-c08-04**(中等):$2\cos t\cos2t+\sin t\sin2t=\frac32\cos t+\frac12\cos3t$(积化和差核对 ✓);第一环 $[\frac32\sin t+\frac16\sin3t]_{-\pi/2}^{\pi/2}=3-\frac13=\frac83$ → 面积 $\frac43$;全周期正交性 → 有向和 0 ✓
5. **draft-c08-05**(进阶):微元 $|y|dx=|y|x'dt$ 推导与分段绝对值规则 ✓

### C09 旋转体体积

1. **draft-c09-01**(基础):$\pi\int_0^4x\,dx=8\pi$ ✓
2. **draft-c09-02**(基础):$2\pi\int_0^1x^3dx=\frac\pi2$ ✓
3. **draft-c09-03**(中等):$\pi(\frac13-\frac15)=\frac{2\pi}{15}$ ✓
4. **draft-c09-04**(中等):$2\pi(\frac14+\frac13)=\frac{7\pi}6$ ✓(轴平移半径 x+1)
5. **draft-c09-05**(进阶):$V_x=\pi\cdot\frac\pi2=\frac{\pi^2}2$;$V_y=2\pi\cdot\pi=2\pi^2$($\int_0^\pi x\sin x\,dx=[\sin x-x\cos x]_0^\pi=\pi$ ✓)

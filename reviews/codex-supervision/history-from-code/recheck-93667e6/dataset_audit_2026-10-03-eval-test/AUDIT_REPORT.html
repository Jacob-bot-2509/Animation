4.2 硬伤明细（3 条，同一题目的 3 个解法）

eval 记录 test 记录 set 口径 multiset 口径

  • eval 题干：设 A=[[1,1],[0,1]]，求 A^n；test 题干：设 A=[[1,2],[0,1]]，求 A^n —— 同一模板仅改常数，属"改数字的同一题"，违反 EVAL_TEST_PREP §1"test 题目不得来自 train 或 eval"。

4.3 项目自带预检的盲区（需补）

tools/eval_test_prep.py check 只在 候选 vs train 之间做近重复，eval 与 test 之间仅比较精确哈希与 ID（_group_sets 只取 canonical_problem_hash 与 record_identity），因此本次 0.7619 的跨角色近重复不会被它拦下。建议把 ShingleIndex 也用于 eval↔test 组间比较。

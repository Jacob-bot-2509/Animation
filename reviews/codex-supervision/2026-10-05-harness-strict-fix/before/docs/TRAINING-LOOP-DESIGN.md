# 训练自动化循环设计(harness 执行)

> 2026-10-05,用户拍板:分层目标 + 上限 8 轮 + 连续 3 轮平台停;
> 残余硬题进人工队列。门禁解锁前循环自检拒绝执行。

## 1. 任务与指标定义(按题计,eval 100 题 / test 150 题)

训练任务:problem + solution → scene_spec(动画规划 JSON;不直接训练 Manim code)。

每轮四项指标(按题计,不合并、不假绿):

| 指标 | 定义 | 分层目标 |
|---|---|---|
| R 渲染成功率 | 题生成 scene_spec 后经渲染管线产出可解码 PNG/MP4 | **100%** |
| E 可执行率 | scene_spec 通过 schema 校验 + 沙箱渲染全流程无异常 | **≥95%** |
| M 数学正确率 | 动画内容与题解一致(逐题数学断言/复核) | 尽力逼近,不设硬线 |
| F 画面忠实度 | 语义核对(曲线/步骤/对象忠实于该题) | 尽力逼近,不设硬线 |

**停止条件**:R=100% 且 E≥95% 达成即停(分层目标);或连续 3 轮无任何指标改善(平台停);或达到 8 轮上限。M/F 未达标的题进入**人工硬题队列**。

**防过拟合铁律**:eval/test 题文绝不出现在训练数据或提示词示例中;每轮同时盯 test 集泛化,报告 eval/test 双列。

## 2. 每轮循环(7 步)

1. **门禁自检**:preflight --ready(含 run-id 快照)——未 ready 立即停,不绕过;
2. **快照**:run_record 建轮次 run_id,登记配置/数据/模型哈希;
3. **训练**:LoRA(轮次/学习率/epoch 从 rounds 配置读;超参未定案时本步拒绝执行);
4. **生成**:eval+test 全部题在沙箱内生成 scene_spec(exec_isolation 解锁后);
5. **四指标验收**:schema/渲染/数学断言/语义核对,逐题落证据;
6. **报告**:轮次 JSON+MD(含指标、失败明细、哈希)追加总日志;
7. **决策**:达标停 / 失败样本回灌(下轮增强,遵守防过拟合铁律)/ 平台停 / 上限停。

## 3. 安全边界

- 门禁自检前置,任何 gate FAIL 即停;
- 生成与渲染只在 AppContainer 沙箱 + JobObject 内执行;
- 每轮证据链完整(run_id/配置/数据/产物哈希),Codex 可审;
- 支持 stop 文件中止(runs/loop.stop),下一轮开始前检查;
- 循环不自动改门禁/数据/冻结/标注——只读写轮次产物目录。

## 4. harness 执行方式

- `tools/train_loop.py` 后台长跑(单进程编排全部轮次);
- 每轮报告落盘后我收到通知;异常/完成我汇总给用户;
- 人工硬题队列每轮自动收集(runs/loop-*/hard-queue.json),攒批由用户处理。

## 四、结论与路线

1. **候选全收,分三库**:题源库(NuminaMath/TheoremQA)、风格参照库(四个 manim 类)、
   验收样例库(ManiBench)。
2. **许可红线**:四个 manim 类未标许可 → 一律不直接进训练数据;先走"人工研读提炼风格模式"
   (学习风格不复制数据,无需许可),必要时联系作者补授权;数据门禁要求 license 逐条登记,
   未标者进 quarantine。
3. **TheoremQA 缺口**:无逐步解答,须先生成解答(LLM)→ Codex 审查链 → 才可作训练素材。
4. **holdout 保护**:所有外部题源进训练前跑泄漏筛查(与 holdout 391 真题比对),项目现成工具。
5. **节奏**:现有 47+311 自编语料的 scene_spec 已是图解式(抽检:切线动态演示/剪切变换面积保持),
   数据质量地板不低;先跑通试训网格看真实生成质量,再按"哪科弱补哪科"定向导入。
6. **用户拍板(2026-10-17)**:NuminaMath 抽样**上限 2000 道**(上限非目标;先抽第一批每学科
   30~50 条共 ~300 试训,按质量信号扩量)。注意:NuminaMath 以竞赛/中学题为主,抽样补的是
   题面广度与风格泛化,高等数学深度仍靠自编+TheoremQA;抽样须按学科配额+难度分层+
   holdout 391 泄漏筛查,门禁后桥上同步 Codex 再执行。

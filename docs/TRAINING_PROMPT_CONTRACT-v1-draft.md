# 训练提示词契约草案 v1(治本:100% 严格解析)

> 状态:草案,待复查方与用户确认后并入训练 SYSTEM。
> 依据:任务可学性探针(03eb5f2)实测——重试闭环达 100% 严格解析,但首轮仅 75%;
> 失败定类:5/5 中 4/5 为 JSON 内 LaTeX 单反斜杠转义错误,1/5 为提前终止。
> 治标=重试+修正指令(已上线);治本=本契约写入训练提示词,目标首轮严格解析率 ≥ 95%。

## 1. 输出契约

- 只输出**一个合法 JSON 对象**,无任何前导/尾随文字、无代码块围栏、无解释;
- 顶层字段与数据模式一致:`id / problem_id / solution_id / method / category /
  sub_category / problem / solution / answer / scene_spec{objects,steps} /
  function_family / visual_style / efficiency_tags / source / license`;
- 输出必须以 `}` 结尾并停止,不得续写评注("以上是…""希望对你有帮助"等即失败)。

## 2. LaTeX 转义规则(本次失败主因,必考)

1. 数学公式必须用 `$...$` 定界(行内)或 `$$...$$`(独立行);
2. **JSON 字符串内**每个 LaTeX 反斜杠必须双写:`\\frac`、`\\lim`、`\\to`、
   `\\displaystyle`、矩阵行分隔 `\\\\`(四个,LaTeX 的 `\\` 转义后);
3. 禁止出现 JSON 字符串内的**单**反斜杠(如 `\frac`):注意 `\f` 会被
   JSON 合法解析为换页控制符、`\t/\n/\b/\r/\u` 同理——**解析成功但语义已毁**;
   因此校验必须是"严格 json.loads + 解析后 LaTeX 语义核验(无裸控制字符、
   无反斜杠后接非 LaTeX 命令字符)";
4. 数学段内不得混入中文与中文标点(中文留在数学段外);
5. 特殊字符按 JSON 转义:`"` → `\"`。

## 3. 内容要求(与数据集规范一致)

- problem/solution 公式写全、不得省略推导、不得"过程略";
- answer 必须含确切值,不得仅有估算结果;
- scene_spec 按解法给出动画对象与步骤(与 v2 每解动画要点口径一致)。

## 4. 自检规则(输出前)

- 输出前在思维内验证:该字符串能被 `json.loads` 严格解析;
- 验证所有 LaTeX 段均满足第 2 节;
- 验证不存在未闭合的 `$`、`{`、`}`。

## 5. 失败分类与修正指令(与探针重试闭环同口径)

| 失败类 | 修正指令要点 |
|---|---|
| JSON 解析失败(单反斜杠等) | "输出必须是严格合法 JSON:LaTeX 反斜杠一律双写,重新生成" |
| 字段缺失/类型错误 | "补齐全部必需字段,类型与模式一致" |
| 提前终止 | "必须输出完整 JSON 并以 } 结尾" |

## 6. 验证计划

1. 契约并入 SYSTEM 后,用探针同一 20 条冻结样本测**首轮**严格解析率;
   **≥95% 仅为目标值,未复测达标前不得称已达**;与现治标闭环的
   "重试后 100%"作对照;
2. 未达标则回查失败定类,调整契约措辞或样本分层;
3. 达标后契约冻结为训练数据的一部分(所有训练样本同口径)。
